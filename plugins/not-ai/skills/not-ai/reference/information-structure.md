# Information structure: given before new

Read this reference when a paragraph feels scattered even though each sentence
is clear. Order carries meaning.

## Principles

- **Given before new:** each sentence should reuse something the reader knows
  (a referent, term, or situation) before adding new information.
- **Topic-comment progression:** the paragraph topic stays stable while comments
  advance it; drifting topics need headings or splits.
- **Referential continuity:** pronouns, names, and terms point unambiguously;
  lexical chains (repeated content words, synonyms the brief allows) carry the
  thread.
- **Paragraph roles:** claim, evidence, mechanism, example, qualification,
  contrast, setup, request, instruction, warning, transition, reflection,
  conclusion. A paragraph with no role is a deletion/merger candidate
  (`not_ai_core/information_structure.py`).

## Pragmatic questions (not slogans)

- Relevance: does this sentence serve the paragraph's job?
- Quantity: does it add information or repeat it?
- Clarity/ambiguity: can the reader resolve every reference?
- Inference burden: who does the work — the text or the reader?

Fix order before wording: move the useful information first, then clarify.
