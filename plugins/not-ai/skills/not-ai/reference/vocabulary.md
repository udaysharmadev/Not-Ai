# Vocabulary review

Read this reference when stock wording is dense enough to obscure the actual
claim. Individual words are never banned.

Corpus studies and Wikipedia editing experience show that model output can
overuse clusters such as `delve`, `tapestry`, `pivotal`, `robust`, `showcase`,
`underscore`, and `vibrant`. The cluster changes across model versions and also
appears in human writing. Treat it as a prompt to read, not as an authorship
signal.

## Review by function

### Inflated importance

Examples include `plays a crucial role`, `serves as a testament`, and
`underscores the importance`. Ask what happened or what follows. State that if
the source supports it; otherwise remove the claim or mark the missing support.

### Vague authority

Examples include `experts agree`, `studies show`, and `observers note`. Name the
source and its actual finding. If no source is available, preserve uncertainty
or remove the appeal to authority.

### Vague relationship

Examples include `in connection with`, `associated with`, and `at the
intersection of`. Name the relationship: ownership, cause, collaboration,
location, timing, or comparison.

### Emotional shorthand

Examples include `inspiring`, `humbling`, `incredible`, and `meant a lot`.
Retain the phrase when it is the writer's real choice. If the piece needs more
specificity, use a supplied action or detail. Ask for one when the source has
none.

### Precise or characteristic language

Keep a flagged word when it is a technical term, quotation, normal expression
in the genre, or a demonstrated habit of the writer. A rare word can be exactly
right. A common word can still be empty.
