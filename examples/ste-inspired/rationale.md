## Rationale: inspired vs verified

General clarity would already fix most of this (actors, order, concision). STE-inspired adds: one instruction per sentence, imperatives, conditions/warnings before actions, synonym control, -ing restraint — all as review prompts citing the official standard's rule families. `technical-ste-verified` would additionally check the user's own dictionary/glossary files and quote their entries. The official STEMG dictionary is never bundled. AI output can look STE-like without complying; this example keeps that warning on the output itself.
