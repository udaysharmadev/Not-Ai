Run `cachectl init --ttl 3600` to initialize the local replica cache before starting the worker daemon. Version 2.4.1 requires Python 3.10+ and loads connection endpoints from https://internal.example.org/config/v2.json at startup. If the Redis socket at `127.0.0.1:6379` does not respond within 1.5 seconds, the worker enters read-only snapshot mode and exits with status code 78 unless you pass `--allow-stale`.
